# Extension design exploration

## Confirmed brief

The user chose one shared design system for the entire extension, with Inbox list
and detail as the first complete sample. A clear visual redesign is permitted.
Production implementation follows the design work rather than preceding it.
The existing product and interaction contracts remain authoritative. Personal use
is the confirmed audience; the working build-path preference remains code-first.

The unique mechanism is an explicitly initiated webpage capture with independent
acquisition, local retention and Locus save outcomes. The first sample must let
the owner inspect content, understand attention/staging, and find the supported
next action without confusing these outcomes.

## Scope

The shared system covers type, light/dark color roles, spacing, shapes, depth,
component states, focus and motion. It must reach the results workspace, settings,
queue dialog and webpage controls. Webpage controls must remain legible within
their host contexts; shared semantics do not require identical surrounding chrome.
No new acquisition, search, delivery, permission or persistence capabilities are
authorized by the visual redesign.

The existing webui/architecture interaction cluster remains converged. This visual
exploration consumes its contracts; it does not reopen them or introduce a new
logical owner. Design structure validation passed on entry.

## Direction round

The Impeccable seed assigned grounded candidate 7, Signal shelf. Candidate 1 is
the single independent pick. The seed key is `0e7c3974`; scope is direction and
mode is Operate. This is exploratory assignment metadata, not user approval.

The seed's catalog challengers were translated into the actual task before being
compared on audience identification and product clarity:

- Emission-line rail: declined. Strict alignment survives; spectral decoration and
  tiny line-only state do not help the task.
- Bitmap specimen: declined. Deliberate type roles survive; display pixel texture
  distracts from ordinary inspection.
- Lexicon shoulder and color plate: competitive on audience identification. A
  useful reading measure and entry rhythm remain viable, with practical controls.
- Convention catalogue: declined on available product evidence. A thumbnail-first
  index conflicts with the deliberate summary-only list; compact scan rhythm survives.
- Airport sign system: competitive on product clarity. A concise supported-action
  sign remains viable; a committed yellow shell risks competing with the content.
- Star atlas: declined. Label ranking survives; coordinates and plotted relationships
  lack product evidence and must not be fabricated.

Signal shelf incorporates the declined challengers' alignment discipline, explicit
type roles, compact repeated scanning and semantic ranking without adopting their
decorative motifs. The full alternatives are Collection room, Reference pages and
Clear route. A quiet conventional category option and re-roll/steer remain available.

## First sample and review boundary

Use plausible, explicitly synthetic Twitter/X and Bilibili content. Demonstrate
staging without configuration, failed/uncertain Locus saving, partial capture,
local-retention failure, empty/search states, loading, and success. Do not imply
that three outcomes are a sequential progress wizard.

The design must address narrow-window focus continuity, failure-label contrast,
truthful search wording and the discoverability of supported recovery. Preserve
named clear confirmation, original-attempt continuation and background focus rules.

The current review covers direction selection. Palette values in the decision
board are proposals, not verified shipping tokens. A chosen direction will be
expanded into a design sample and specification before production implementation.
DESIGN.md and its sidecar must be grounded in that reviewed sample, not presented
as a description of the unchanged current production UI.

## Selected direction

The user explicitly selected Signal shelf in chat. The local decision board
recorded `assigned`, build path `code`, with no workflow flip. The next delivery
is a reviewed interactive design sample and its extension-wide specification;
production changes follow this design delivery.

The user subsequently narrowed the selected system to dark mode only. The sample
and normative design tokens use the mineral-blue dark palette with no theme switch.
